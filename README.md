무꾸리 사건 보관소 · 흑백 배경 에디션

실행 방법
압축을 풀고 index.html을 Chrome 또는 Edge에서 열어 주세요.
index.html, style.css, dark-theme.css, app.js, assets 폴더는 같은 곳에 두어야 합니다.
별도 설치 없이 실행할 수 있고 정적 호스팅에도 그대로 올릴 수 있습니다.

변경 사항
- 메인 화면 오른쪽의 소개 문구와 작업 표시줄의 배경 조작 표시를 삭제했습니다.
- 직접 보내주신 이미지 12장만 배경으로 사용했습니다.
- 배경은 화면에서 모두 흑백으로 표시되며 3초마다 전환을 시작합니다. 이전 사진 위로 다음 사진이 약 1.5초 동안 부드럽게 나타납니다.
- 화면 오른쪽을 중심으로 순수 검정색 원형 비네팅을 적용했습니다.
- 배경 사진은 오른쪽의 보이는 영역을 채우고 왼쪽의 검은 배경에 부드럽게 이어집니다. 화면과 사진의 비율이 다르면 가장자리가 일부 잘립니다.
- 작품, 안내와 구매처 파일, 창의 내용 및 기존 상품 이미지는 유지했습니다.
- 기기에서 동작 줄이기를 사용해도 요청하신 배경 크로스페이드는 유지됩니다. 다른 화면 동작은 기기 설정을 따릅니다.

사용 방법
파일을 한 번 클릭하면 소개가 열립니다. 마우스나 손가락으로 파일을 끌어 옮길 수 있습니다.
위치는 같은 브라우저에 화면 크기별로 저장되며 시작 메뉴에서 초기화할 수 있습니다.
창의 제목줄을 드래그하여 이동하고, 오른쪽 위에서 최소화·최대화·닫기가 가능합니다.
최소화한 창은 작업 표시줄에서 다시 열 수 있습니다. Esc 키로 창을 닫을 수 있습니다.

파일 설명
index.html: 화면과 배경 이미지 목록
style.css: 기본 배치와 파일 및 창 디자인
dark-theme.css: 흑백 배경과 다크 색상
app.js: 자동 전환, 파일 드래그, 창 조작
assets/: 사용 이미지와 아이콘
ASSET_SOURCES.md: 이미지 출처 및 적용 기록

이 ZIP에는 웹사이트 소스가 들어 있습니다. 기존 운영 사이트에 자동으로 배포되지는 않습니다.
