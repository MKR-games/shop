압축을 푼 뒤 index.html을 Chrome, Edge, Safari 등에서 여세요.
index.html, style.css, app.js, assets 폴더를 같은 위치에 두면 됩니다.
별도 설치나 서버 없이 볼 수 있는 정적 사이트입니다.

이번 적용
- 기존 캐릭터·상품 목업·전시 사진 등 10개 자료를 선별해 사용했습니다.
- 복도 → 무꾸리 작업실 → 전시 공간 배경이 약 10초 간격으로 바뀝니다.
  두 이미지가 2.8초 동안 겹쳐 부드럽게 전환됩니다.
  화면 아래 중앙에서 일시정지하거나 다음 배경으로 넘길 수 있습니다.
- 바탕화면 아이콘을 마우스나 손가락으로 드래그할 수 있습니다.
  클릭하면 소개가 열리고, 드래그 직후에는 소개가 열리지 않습니다.
- 위치는 같은 브라우저에 화면 크기별로 저장됩니다.
  Info → 아이콘 원래 위치로에서 모두 초기화할 수 있습니다.
  저장을 차단한 브라우저에서도 이동과 소개 열기는 작동합니다.
- 팝업은 제목 표시줄을 드래그해 이동하고, □ 버튼으로 확대·복원합니다.
  제목 표시줄을 두 번 눌러도 확대·복원할 수 있습니다.
  ×, 바깥 배경 클릭, Esc 키로 닫을 수 있습니다.
- 키보드: Tab으로 파일 선택, Enter로 열기, Shift + 방향키로 위치 이동,
  Shift + Home으로 선택한 파일 위치 초기화. 팝업 안에서는 포커스가 유지됩니다.
- 운영체제의 '동작 줄이기' 설정을 켜면 배경 자동 전환과 모션을 중지합니다.
- 전체 문서 보기와 스크립트 없는 기본 소개 링크도 유지했습니다.

파일
index.html : 메인 화면과 7개 소개 창
style.css : 바탕화면, 창 장식, 반응형 스타일
app.js : 배경 전환, 드래그·위치 저장, 팝업 제어
assets/ : 실제 적용한 10개 경량 이미지·벡터
ASSET_SOURCES.md : 적용 이미지와 원본 기록

상품별 구매 버튼은 기존에 제공된 공식 판매 링크를 유지합니다.
이번 파일은 로컬 확인용이며 실제 운영 사이트 배포는 포함하지 않습니다.
